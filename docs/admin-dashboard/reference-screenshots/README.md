# Referências visuais do Admin

Coloque aqui os prints do SEMS+ que servirão de referência para reconstruir o Dashboard Admin com a camada ChargeGrid.

## Organização

- `inbox/`: capturas novas ainda não catalogadas.
- Use, quando possível, o padrão `SEMS-<DOMINIO>-<TELA>_<PAPEL>_<VIEWPORT>_<ESTADO>.png`.

Exemplo: `SEMS-ENERGY-DASHBOARD_OWNER_1440x900_POPULATED.png`.

Ao enviar uma captura, informe em uma mensagem a rota ou o nome da tela e o que ela representa. Não inclua senhas, tokens, cookies, e-mails completos, dados pessoais ou ativos reais.

As capturas históricas sanitizadas continuam em `docs/sems-analysis/screenshots/`; esta pasta é o espaço de trabalho para a próxima reconstrução visual.
