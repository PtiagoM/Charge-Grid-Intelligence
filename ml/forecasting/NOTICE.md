## NREL Workplace Charging Data

Christopher Neuman, Andrew Meintz, and Myungsoo Jun, *Workplace Charging Data*, NLR Data Catalog, DOI [10.7799/1838140](https://doi.org/10.7799/1838140), version “Data Set Oct 2021”, downloaded from <https://data.nlr.gov/submissions/182>. The composite uses session energy and timestamps to estimate uniform average power over intervals; it does not redistribute the source CSV or driver identifiers.

## EULP / ComStock

NREL/LBNL, *End-Use Load Profiles for the U.S. Building Stock*, ComStock AMY2018 Release 1, 5B SmallOffice, distributed through [OEDI](https://data.openei.org/submissions/4520). The catalog/source metadata declares [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Adaptation: aggregate 15-minute energy was divided by the model count and interval duration, then calendar-aligned into this explicitly simulated composite. Attribution: NREL and Lawrence Berkeley National Laboratory (LBNL).

## NREL PVDAQ

NREL, *Photovoltaic Data Acquisition (PVDAQ) Public Datasets*, DOI [10.25984/1846021](https://doi.org/10.25984/1846021), system 10, accessed through [OEDI](https://data.openei.org/submissions/4568). The [Data.gov dataset catalog](https://catalog.data.gov/dataset/photovoltaic-data-acquisition-pvdaq-public-datasets) lists [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribution: NREL. Adaptation: four daily readings were resampled to 15-minute means, negative values clipped to zero, converted from W to kW, and scaled using the 1.12 kW reference nameplate to an explicitly hypothetical 75 kWp scenario. The [PVDAQ data dictionary](https://github.com/openEDI/documentation/blob/main/pvdaq.md) defines `measured_on` as local time and requires metric metadata to interpret units; it also documents that cadence varies by system.
